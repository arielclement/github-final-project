# GitHub Final Project

A calculator that computes **simple interest** given:

- Principal amount (`p`)
- Annual rate of interest (`r`)
- Time period in years (`t`)

## Formula

```text
Simple Interest = (p × t × r) / 100
```

## Input

| Variable | Description |
|----------|-------------|
| `p` | Principal amount |
| `t` | Time period in years |
| `r` | Annual rate of interest |

## Output

| Value | Description |
|--------|-------------|
| Simple Interest | `(p × t × r) / 100` |

## Example

### Input

```text
p = 1000
t = 2
r = 5
```

### Calculation

```text
Simple Interest = (1000 × 2 × 5) / 100
                = 100
```

### Output

```text
100
```
